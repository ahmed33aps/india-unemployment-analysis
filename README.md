# India unemployment analysis

Exploration of unemployment trends across regions and urban/rural areas.

## Contents

- `Unemployment in India.ipynb`
- `Unemployment in India.csv`
- `Unemployment_Rate_upto_11_2020.csv`

## Run

Use Python 3.11+ in a virtual environment, then install dependencies:

```sh
python -m pip install -r requirements.txt
jupyter notebook
```

Open a notebook from this repository and run it from the repository root.
